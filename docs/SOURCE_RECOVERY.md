# استعادة سورس سرفيسنا

في 15 تشرين الثاني 2026 تم استلام أرشيف مصدر Replit، وفحصه وتجهيزه للاستيراد.

## النسخة المستعادة
- 303 ملفات Git متتبَّعة في المراجعة 71fdfd9 من المشروع الأصلي، دون مجلد Git الخاص ببيئة Replit.
- واجهة React، خادم API، تعريفات وترحيلات قاعدة البيانات، اختبارات، وثائق المشروع وملفات إعداد pnpm.
- الأرشيف المنظف متاح في `archive/srfysn-source-clean.zip` للتحقق من البصمة SHA-256.
- ملفات `.git` القديمة ومخرجات البناء و`attached_assets` غير المتتبعة لم تُرفع.

**التحقق:** نجح فحص محتويات الأرشيف وتحقق البصمة. تنفيذ الاختبارات وبناء التطبيق على GitHub لم يُتحقق منه بعد. لا تضع بيانات ركاب حقيقية أو أسرار تشغيل داخل المستودع العام.
