# ما أمكن التحقق منه من الموقع المنشور

تاريخ الفحص: 2026-11-15  
الرابط: https://srfysn.replit.app/

تحقّقنا من وجود نشر فعّال لدى Replit ومن المحتوى النصّي العلني للصفحة الرئيسية. هذه **لقطة توثيقية**، وليست نسخًا لملفات HTML أو CSS أو JavaScript أو الخادم.

## المعلومات الظاهرة للعامة

- عنوان المشروع: **سرفيسنا**.
- عنوان الواجهة: **«أي سرفيس؟ ومن أي موقف؟»**.
- وصف الخط: **الوعر ↔ وسط حمص**، وتوجيه الركاب إلى نقطة الانتظار الملائمة لاتجاه السرفيس.
- بوابة دخول بالحسابات التجريبية للعرض؛ الصفحة تقول إن التحقق برسائل SMS للحسابات الحقيقية سيأتي لاحقًا.
- ثلاثة أنواع من الأدوار في العرض: **راكب، سائق، إدارة**.
- حسابات عرض بأسماء: سارة الحمصي، عمر الأتاسي، ليلى الدروبي (ركاب)؛ أبو خالد، أبو سامر، محمود السباعي (سائقون)؛ إدارة سرفيسنا.
- وصف على صفحة الدخول: رقم هاتف الراكب لا يظهر للسائق إلا بعد قبول الطلب.

## حدود التحقق

- لا تثبت هذه اللقطة أن تدفقات الطلب والقبول والركوب وإنهاء الرحلة أو حماية البيانات تعمل كما هو متوقع.
- لم يتم الوصول إلى السورس الأصلي أو ملف قاعدة البيانات أو مخطط الجداول أو السجلات أو الأسرار.
- أي ميزة داخل المواصفات المرفقة هي **متطلب تاريخي** ما لم يتم اختبارها مباشرةً في نسخة التطبيق.

**مهم:** لا تنسخ أرقام الهواتف أو بيانات الرحلات الفعلية إلى مستودع عام أثناء الاسترجاع.
