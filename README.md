# سرفيسنا | Sarvisna

**سرفيسنا — على خطّك**: نموذج تطبيق عربي لتنسيق طلبات الركوب على خطوط السرافيس في حمص، مع واجهات للراكب والسائق والإدارة.

- التطبيق المنشور: https://srfysn.replit.app/
- مشروع Replit: https://replit.com/@qut2006sib/srfysn
- الحالة: **استعادة جزئية للوثائق فقط، وليست نسخة من الكود المصدري** (15 تشرين الثاني 2026).

## ما المتاح في هذا المستودع؟

- [مواصفات نسخة المسابقة](docs/Sarvisna-Replit-Competition-Spec-AR-v0.1.md): ملف محفوظ بتاريخ 3 تشرين الثاني 2026، وهو مواصفات مقترحة قبل التنفيذ، **وليس تقريرًا يؤكد أن كل البنود نُفذت**.
- [لقطة توثيقية عن الموقع المنشور](docs/LIVE_SITE_SNAPSHOT.md): ما أمكن التحقق منه من صفحة الدخول العامة.
- [حالة استعادة المصدر](docs/SOURCE_RECOVERY.md): ما توفّر وما تعذّر استرداده وكيفية إكمال النسخة الاحتياطية.

## تنبيه هام

الكود الأصلي من بيئة Replit (ملفات العميل والخادم، إعدادات البناء، قاعدة البيانات، الترحيلات والاختبارات) **لم يُسترجع هنا بعد**. لا يمكن استخدام هذا المستودع حاليًا لتشغيل التطبيق. لم تتم إعادة توليد ملفات باسم السورس الأصلي، كي لا تختلط الوثائق بكود لم يتم التحقق منه.

> لا ترفع ملفات `.env` أو مفاتيح API أو كلمات المرور أو نسخ قواعد بيانات المستخدمين إلى مستودع عام.
