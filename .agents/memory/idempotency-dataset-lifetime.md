---
name: Demo dataset lifetime
description: Resetting dynamic demo data does not create a new idempotency dataset
---

إعادة تهيئة بيانات العرض لا تبدأ مجموعة عرض جديدة بالنسبة لمفاتيح المحاولات.

**Why:** قد يصل تكرار reset قديم بعد تحضير بيانات أحدث؛ حذف سجل المحاولة يجعل التكرار يمسح تلك البيانات مرة ثانية بدل إعادة نتيجته الأصلية.

**How to apply:** حافظ على سجل المحاولات عند reset. إذا أضيف لاحقًا مفهوم مجموعة عرض مستقلة جديدة، فلتكن له هوية ونطاق صريحان بدل اعتباره أثرًا ضمنيًا لإفراغ الطلبات والرحلات.
